# Welcome to Markdown Viewer

A fast, modern workspace for browsing and editing Markdown files, rendered by a **.NET backend** and a clean, dependency-free frontend.

## What you're looking at

This is a small folder of sample notes (`SampleDocs/`) that ships with the app so there's something to click around in right away. Everything you see — file tree, search, rendering, editing — talks to the ASP.NET Core API running underneath.

## Highlights

- Full GitHub-flavored Markdown: tables, task lists, footnotes, strikethrough
- Syntax-highlighted code blocks in dozens of languages
- Live-rendered [Mermaid](https://mermaid.js.org) diagrams
- Math typesetting via KaTeX, both inline like $E = mc^2$ and in display blocks
- A sticky, auto-generated table of contents
- Light and dark themes that respect your system preference
- A split-pane editor with live preview and one-click save

## Try it

1. Open **Features → Formatting Showcase** in the sidebar to see everything rendered at once.
2. Click the pencil icon in the toolbar to switch this page into edit mode.
3. Use the search box in the sidebar to find text across every file.

> Tip: headings automatically get anchor links, so the table of contents on the right always stays in sync with what's on the page.
